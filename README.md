# jibinmadayil.github.io

Personal site of Jibin Madayil John, Oracle Fusion Financials and EPM consultant. Served by GitHub Pages from `main`.

- `index.html`: the page
- `styles/site.css`: styles and design tokens (light and dark themes)
- `scripts/site.js`: navigation, theme toggle and scroll animations
- `img/`: portrait and social preview image
- `Jibin_Resume.pdf`: the CV behind the Download CV button

No build step. Edit the files and push.
